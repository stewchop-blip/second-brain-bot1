# Второй мозг (Second Brain Bot)

Telegram-бот, который помогает быстро критически взглянуть на свои идеи, вычитать текст перед отправкой и выбрать оптимальный вариант из нескольких.

## Три режима

| Режим | Что делает |
|-------|-----------|
| **💥 Оспорить** | Критический анализ идеи: риски, слабые места, как проверить дёшево |
| **✉️ Проверить сообщение** | Анализ тона, стиля, грамматики + улучшенная версия текста |
| **⚖️ Помочь выбрать** | Сравнение вариантов по критериям + обоснованная рекомендация |

## Быстрый старт (локально)

```bash
# 1. Скопируй .env.example → .env и заполни
cp .env.example .env

# 2. Установи зависимости
pip install -r requirements.txt

# 3. Запусти (polling mode)
python bot.py
```

## Деплой на Render

1. Запушь репо на GitHub
2. На [render.com](https://render.com) создай Web Service из `render.yaml`
3. Добавь env vars: `BOT_TOKEN`, `OPENROUTER_API_KEY`
4. Готово — бот автоматически настроит webhook

## Архитектура

```
bot.py          — точка входа (webhook/polling)
handlers.py     — FSM для 3 режимов + меню
llm_client.py   — OpenRouter клиент с ретраями
db.py           — PostgreSQL (asyncpg): users, limits, history
prompts.py      — системные промпты для каждого режима
config.py       — конфиг из env vars
```

## Ограничения

- **Лимит**: 20 запросов/день на пользователя
- **Макс. длина сообщения**: 4000 символов
- **История**: последние 10 диалогов для контекста
